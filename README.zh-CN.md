# PlanRec-Agent

> 代码快照发布说明：仅含筛选源码，不含模型、数据、日志或凭据。

PlanRec-Agent 是一个生成式推荐研究项目，围绕语义计划、候选生成和预算约束下的排序评估构建可复现实验流程。项目强调预先声明的实验门槛、完整目录评估和保留阴性结果。

## 主要内容

- 推荐模型与语义 ID 生成组件
- 训练、全目录评估和结果审计脚本
- 实验配置、单元测试与可追溯报告

## 快速开始

这是筛选源码快照，不是完整可运行版本。保留的部分测试引用了未发布的 `planrec.data.amazon`、`preprocess_amazon_2014` 和 `scripts/fetch_cloud_artifact.py`，因此不能直接运行完整测试套件。不要为补齐引用而复制私有数据或工作区材料。可运行发布需要另行审查自包含的代码子集并说明依赖。

## 结果说明

实验结论以每个实验的冻结协议和报告为准。不同数据集、阶段或候选模型的结果不能混用；工程测试通过不等于推荐效果提升。
