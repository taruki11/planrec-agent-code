# PlanRec-Agent

> Code-only source snapshot. Models, datasets, run logs, and credentials are excluded.

PlanRec-Agent is a generative recommendation research project with reproducible workflows for semantic planning, candidate generation, and budget-aware ranking evaluation. It emphasizes preregistered gates, full-catalog evaluation, and honest reporting of negative results.

## Contents

- Recommendation models and semantic-ID generation components
- Training, full-catalog evaluation, and audit scripts
- Configurations, unit tests, and traceable reports

## Getting started

This selected source snapshot is not a complete runnable release. Some retained tests reference omitted modules, including `planrec.data.amazon`, `preprocess_amazon_2014`, and `scripts/fetch_cloud_artifact.py`; the full test suite cannot run from this snapshot. Do not copy private data or workspace materials into this repository to satisfy those imports. A runnable release requires a separately reviewed, self-contained code subset and documented dependencies.

## Results

Interpret each experiment only under its frozen protocol and report. Do not mix results across datasets, stages, or candidate models. Passing engineering tests does not demonstrate a recommendation-quality improvement.
